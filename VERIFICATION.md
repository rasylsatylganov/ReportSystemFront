# Проверка подготовленного проекта

- Установлены зависимости из нового package.json.
- Сформирован соответствующий package-lock.json с источниками registry.npmjs.org.
- Успешно выполнен npm run build: проверка типов vue-tsc и production-сборка Vite.
- В браузере проверены пустая рабочая область, верхнее меню и переключение на тёмную тему.
- После перезагрузки открывается светлая тема; сохранение темы между запусками пока не добавлено.
- При проверке backend не запускался и не требовался.
- Исходные версии основных библиотек сохранены по lock-файлу примера.
- В архив не включены node_modules, dist, настройки окружений и учётные данные другого проекта.

Сборка проверена на Node.js 24.22.1 и npm 11.9.0. Для запуска нужен Node.js >=22.12.0.
Проверка в Windows и подключение к Java API не выполнялись.

Vite разрешает localhost и terminal.local для локальной разработки и внутренней проверки.
Настройки окружений и корпоративного прокси при установке зависимостей задаются на вашем компьютере.
